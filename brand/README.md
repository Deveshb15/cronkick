# Cronkick brand

**Mark:** the slot tile. Three counted slots and a fourth that kicks forward, on time. The slots are cut out of the tile, so the symbol works in one colour on any background.

| File | Use |
|---|---|
| `cronkick-symbol.svg` | Primary symbol, amber, slots transparent |
| `cronkick-symbol-black.svg` | One-colour black |
| `cronkick-lockup-on-dark.svg` / `-on-light.svg` | Symbol + wordmark (Inter Display SemiBold, outlined, −2.5% tracking) |
| `cronkick-app-icon.svg` | Solid tile with ink slots (app icons, avatars) |
| `web/public/favicon.*`, `apple-touch-icon.png`, `icon-*.png` | Web and PWA icons |

**Colours**

| | Hex | Use |
|---|---|---|
| Amber | `#FFB020` | The tile, primary buttons, the one accent. Never for body text on white. |
| Ink | `#09090B` | Background (dark-first), wordmark on light |
| White | `#FFFFFF` | Wordmark on dark |

**Rules**
- Clear space around the symbol: one slot width (≈ 11% of the tile) on every side.
- Minimum size: 16 px for the symbol; 80 px wide for the lockup.
- Don't recolour the slots, rotate the tile, add effects, or set the wordmark in another font.
- The wordmark is outlines of Inter Display (SIL Open Font License); no font licence is needed to use the files.
